# HeaderSectionController - Fixed Behavior

## ? **Changes Made**

### **Problem:** 
Sections automatically expanded when entering Play mode, even though you just wanted to load the interface.

### **Solution:**
Updated `HeaderSectionController.cs` to:

1. **Start with all sections collapsed** - `HideAllSections()` is called in `Start()`
2. **Only expand when button clicked** - Removed `ShowSection(mechanismsSection)` auto-call
3. **Add toggle behavior** - Clicking the same button again collapses the section

```csharp
    // Start with all sections collapsed ?

```

### **New Toggle Method:**
```csharp
private void ToggleSection(GameObject sectionToToggle)
{
    // If clicking the active section, collapse it
    if (currentlyActiveSection == sectionToToggle && sectionToToggle.activeSelf)
    {
        sectionToToggle.SetActive(false);
        currentlyActiveSection = null;
        return;
    }

    // Otherwise, hide all and show this one
    HideAllSections();
    sectionToToggle.SetActive(true);
    currentlyActiveSection = sectionToToggle;
}
```
