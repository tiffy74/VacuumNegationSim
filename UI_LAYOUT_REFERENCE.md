## **?? User Flow**

### **Scenario 1: Load Preset and Run**
1. Open Right Dock ? Setup Panel
2. Select "Triangle Diffusion" from dropdown
3. Click **"Load Preset"**
   - ? Notification: "? Preset loaded: Triangle Diffusion"
   - ? UI updates (Grid Topology = TriGrid, etc.)
   - ? Simulation NOT restarted yet
4. Click **"Apply"**
   - ? Notification: "? Simulation restarted"
   - ? Simulation runs with Triangle Diffusion preset

### **Scenario 2: Load Preset, Tweak, Then Run**
1. Select "Default" preset
2. Click **"Load Preset"**
   - ? Preset parameters loaded into UI
3. **Change Grid Topology** from RectGrid ? HexGrid
4. **Change Inflow** from Uniform ? PointSources
5. Click **"Apply"**
   - ? Simulation restarts with: Default preset + custom changes

### **Scenario 3: Quick Tweaks (No Preset)**
1. Change Grid Topology to TriGrid
2. Change Diffusion to Moore8
3. Click **"Apply"**
   - ? Simulation restarts with changes
