## ?? **Size Control**

### **LayoutElement Properties:**

```
Preferred Width/Height: 
?? Target size (not enforced)
?? Example: Preferred Width: 420
?? "I'd like to be this size"

Min Width/Height:
?? Minimum size (enforced)
?? Example: Min Width: 400
?? "Don't make me smaller than this"

Flexible Width/Height:
?? Priority for extra space
?? Example: Flexible Width: 1

Usage:

? Pref:420 ? Flex:1           ?
? Flex:0   ? (takes remaining)?
```

## ?? **Debug Checklist**

### **Element Appears in Wrong Location?**

**Check these in order:**

1. **Parent has LayoutGroup?**
   - YES ? Remove manual anchors, use LayoutElement for size
   - NO ? Continue to #2

2. **Anchors set correctly?**
   - Stretch to fill? ? AnchorMin (0,0), AnchorMax (1,1), offsets 0
   - Top-pinned? ? AnchorMin (0,1), AnchorMax (1,1)
   - Check pivot matches intent

3. **Offsets zero?**
   - If anchors stretch, offsets should be 0 (or specific values for padding)
   - If offsets are non-zero, element is shifted

4. **LayoutElement present?**
   - For size control inside LayoutGroup
   - Flexible Width/Height for expansion
   - Preferred Width/Height for target size

5. **Parent RectTransform correct?**
   - Parent must be positioned correctly first
   - Check parent's parent if needed (cascade up)

## ?? **Common Mistakes**

### **? Mistake 1: Default Center Anchors**

```
GameObject has anchors (0.5, 0.5) ? Default
    ?
Element appears in center of screen
    ?
FIX: Set anchors to stretch (0,0) to (1,1)
     OR pin to specific edge
```

### **? Mistake 2: Manual Position with LayoutGroup Parent**

```
Parent has HorizontalLayoutGroup
    ?
Child has manual anchoredPosition set
    ?
Child jumps position, ignores LayoutGroup
    ?
FIX: Remove manual position, use LayoutElement for size
```

### **? Mistake 3: No Size Control**

```
Element inside LayoutGroup
    ?
No LayoutElement component
    ?
Element collapses to minimum size or expands uncontrollably
    ?
FIX: Add LayoutElement with Preferred/Flexible/Min size
```
