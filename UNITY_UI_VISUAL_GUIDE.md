## ?? Layout Group Behavior

### Horizontal Layout Group:
```
?????????????????????????????????????
? ???????? ????????????????????    ?

? ?100px ? ? Flexible (fills) ?    ?
```

**How it works:**
1. Label gets fixed 100px width
2. Input Field gets remaining space
3. Spacing adds gap between them

## ?? Troubleshooting Visual Guide

### Problem: Elements Not Aligned Horizontally

**Wrong:**
```
Label
Input
```

**Fix:** Make sure parent has **Horizontal Layout Group**, not Vertical!

---

### Problem: Element Not Filling Width

**Wrong:**
```
???????????????????????????????????
? Label    [Input    ]            ?
?                     ? too small ?
???????????????????????????????????
```

**Fix:** Add **Layout Element** to Input, set **Flexible Width: 1**

---

### Problem: No Gap Between Elements

**Wrong:**
```
LabelInput
```

**Fix:** In Layout Group, set **Spacing: 10**
