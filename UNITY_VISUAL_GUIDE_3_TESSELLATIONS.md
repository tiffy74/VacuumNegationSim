## **Common Visual Issues**

### **Issue 1: All Cells Overlapping (Incorrect Positioning)**

**What You See:**
```
???????  ? All hexagons in one pile!
```

**Cause:** Cell positions not calculated correctly

**Fix:** Check `GetCellPosition()` returns different values for each (x,y)

---

### **Issue 2: Gaps Between Cells**

**What You See:**
```
?  ?  ?  ? Visible gaps (bad!)
  ?  ?  ?
?  ?  ?
```

**Cause:** Cell spacing too large

**Fix:** Reduce `cellWidth` or increase sprite size

---

### **Issue 3: Cells Too Large (Overlap)**

**What You See:**
```
?????  ? Hexagons overlapping edges
?????
```

**Cause:** Sprite size too large for spacing

**Fix:** Reduce sprite size or increase spacing

---

### **Issue 4: Wrong Sprite Showing**

**What You See:**
- Selected Hexagonal but seeing squares

**Cause:** Sprite not switching based on topology

**Fix:** Check `GetSpriteForTopology()` returns correct sprite
