### **Adding All 4 Detail Sections:**

**Repeat the above for each section:**

1. **Click `+` button** (adds Listener 1)
2. **Drag `TopologyDetailsSection`** ? Select **`RefreshVisibility()`** (no parameters!)

3. **Click `+` button again** (adds Listener 2)
4. **Drag `InflowDetailsSection`** ? Select **`RefreshVisibility()`** (no parameters!)

5. **Click `+` button** (adds Listener 3)
6. **Drag `DiffusionDetailsSection`** ? Select **`RefreshVisibility()`** (no parameters!)

7. **Click `+` button** (adds Listener 4)
8. **Drag `ViabilityDetailsSection`** ? Select **`RefreshVisibility()`** (no parameters!)

**?? IMPORTANT:** Make sure you select the **parameterless** `RefreshVisibility()` method, NOT the one with `(WorkingScenarioConfig)` parameter!

## ?? **Troubleshooting**

### **Event still not visible:**
- Check: Did Unity recompile? (wait for spinning icon to stop)
- Check: MechanismsSection script attached to GameObject?
- Solution: Close/reopen Unity, or reimport script

### **RefreshVisibility() not in dropdown:**
- Check: Detail section script attached to GameObject?
- Check: Script compiles without errors?
- Solution: Check Console for errors

### **Event fires but section doesn't show:**
- Check: RefreshVisibility() implementation in section script
- Check: Console for errors when dropdown changes
- Solution: Debug.Log in RefreshVisibility to verify it's called
